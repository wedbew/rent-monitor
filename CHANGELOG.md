# Changelog

All notable user- and operator-visible changes. Format: [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Security
- Error events no longer carry stack-frame variables, breadcrumb data, log params or emails, JWTs and token-like parameters in free text, and are dropped if scrubbing fails; must be in place before `SENTRY_DSN` is set (RM-149)

### Added
- Worker maintenance (RM-157, **awaiting human review: reads the credit ledger**): nightly `ledger_check` (balance must equal the ledger sum; any mismatch is a Sentry error and a failed heartbeat, never a write), 5-minute `monitor` (queue lag over 10 min, database connections over 70, cgroup memory over 60 %), `remove_old_jobs_ops` / `remove_old_jobs_other` (finished and failed jobs: ops queue after 24 h, others after 7 days), Better Stack heartbeats from the ledger check and the retention sweep, Sentry initialised in the worker; settings `BETTERSTACK_HEARTBEAT_LEDGER_URL` and `BETTERSTACK_HEARTBEAT_RETENTION_URL` (empty = off) (RM-157)
- Setting `GOOGLE_CLIENT_SECRET` (typed secret, never logged; only needed for a server-side code flow, ID-token sign-in uses the client ID alone) added to `Settings` and `.env.example` (RM-123)
- Local pipeline (RM-116): `scripts/ci_local.sh` and `make ci-fast | ci | ci-full` run the same checks as GitHub (commits, lint, types, ty, tests + coverage, invariants with the required-names check, migrations + squawk, semgrep, pip-audit, gitleaks, actionlint + zizmor, optional Docker smoke) before you push; `make hooks` installs commit-msg, formatting and pre-push hooks; `scripts/check_invariants.py` is kept identical to the CI list by a test; new dev dependency `defusedxml`
- Credit ledger, quota and flags (RM-19, **awaiting human review: money**): `rm_core.ledger` (idempotent signup grant, reserve → capture/release with the plan allowance spent before credits, atomic settle claim, admin adjustments, nightly ledger-vs-balance check), `rm_core.entitlements` (`has_pro` failing closed 48 h after period end, grace period, 30-day pass periods), `rm_core.flags` (override → plan gate → rollout bucket → default); no schema change
- AI budget (RM-24, owner-approved): monthly cap with an atomic reserve/settle/release (`PostgresBudgetGate` implements the vision client's `BudgetGate`), per-call token and USD log `app.ai_usage`, 80 % warning (Sentry), cap 0 as kill switch, nightly sweep of holds left by crashed workers; **operator action:** `make migrate` (migration `0005`) (RM-24)
- Geo (N-03): pure distances and nearest points of interest in `deal_analyzer.geo`; `OsmClient` (Nominatim geocoding, Overpass POIs) refusing the placeholder `NOMINATIM_USER_AGENT`, using the shared 1 req/s Postgres slot, bounded responses and one retry; Postgres read-through cache `app.geo_cache` (geocode 90 d, POI 30 d, failures never cached, purged by the retention sweep); **operator action:** `make migrate` (migration `0004`) and set `NOMINATIM_USER_AGENT` with a real contact; attribution requirement recorded as L-008 (RM-86)
- Engine rent estimate (N-04, engine side): `estimate_rent` from comparable asking rents (size-window median PLN/m², IQR outlier trimming, quartile interval; fewer than 3 comparables refuses a number, fewer than 10 lowers confidence); the market-context importers and storage that supply comparables remain the market lane (RM-87)
- Engine golden snapshots (N-10): four hand-built deals pinned as canonical JSON and Markdown under `tests/engine/golden/` (regenerate deliberately with `UPDATE_GOLDEN=1`; every diff must be explained in the PR), whole-pipeline hypothesis properties, and **CI now requires seven named invariant tests** (adds fractional ownership, JSON canonical / Markdown view, LLM clamp) (RM-93)
- Engine assembly and view (N-09): canonical `DealAnalysis` (JSON, schema version 1) built by `analyse_listing` from an extracted listing, rent estimate, risk-free rate and optional vision answer (fractional ownership raises before any math; rents refused below 3 comparables; 3 % asking-rent haircut, labelled asking-based), and `render_markdown` (pl/en) derived from the JSON alone, with test `test_invariant_json_is_canonical_markdown_is_a_view` (every number shown exists in the JSON); assumptions version `2026-10-12.2` (RM-92)
- Engine CAPEX (N-05): `estimate_capex` from condition (vision scale), area and city tier with a ±25 % range and confidence; unknown condition assumes `refresh` with low confidence; **prices are labelled placeholders** (`prices_are_placeholders=True`, limitation L-007, blocker B-015) (RM-88)
- Engine vision outputs (N-08): strictly parsed `VisionOutput` (condition scale, photo kinds, floor-plan text, proposed adjustments; `NaN`, oversized, unknown or malformed answers rejected), `clamp_adjustment` limiting every LLM-proposed adjustment to ±15 % of the deterministic base, `VisionRecord` (model, prompt version, proposed vs applied) for recomputing without the model, renders and staging excluded from the evidence; invariant test `test_invariant_llm_adjustment_is_clamped` (RM-91)
- Engine Max Bid (N-07): `analyse_deal` returns Max Bid (uncapped, by monotone bisection using the NPV-at-hurdle test), hurdle as risk-free + user premium (default 2.0 %), ±1 pp appreciation sensitivity, grade A-E/N by IRR minus hurdle (+3.0/+1.5/0/−1.5 pp) and a verdict label (`buy_at_asking` caps only the label); optional `market_value_pln` exit anchor (RM-90)
- Engine cash flow (N-06): `compute_cash_flows` (10-year, annual, unlevered, after tax) with purchase costs (PCC, notary scale + VAT, copies, court fee, VAT-sale handling), operating costs (admin fee as OPEX, property tax, insurance, vacancy, maintenance, management), ryczałt per owner, sale tax window, exit value, IRR (deterministic bisection), MOIC, CAGR, yields; local `decimal.Context`, rounding at output only; assumptions are versioned constants (tax/notary values flagged for the accountant); invariant tests `test_invariant_admin_fee_is_opex` and `test_invariant_deterministic_math`; **CI: `invariants` job enabled and required** (RM-89)
- Engine classifiers: ownership (title form, whole vs fractional share; `udział w gruncie` is not fractional; accent-folded Polish patterns) with `FractionalOwnershipError` (invariant 5, test `test_invariant_fractional_ownership_rejected`), and legal class (residential / VAT sale / non-residential, gross vs net price basis); `Listing.building_ownership` added (RM-85)
- Engine package `apps/deal_analyzer` (folder = module): bounded, typed `extract_listing` producing an immutable `Listing` with `Decimal` money; RENT listings raise `RentNotADealError` before anything else (invariant 1); `characteristics.rent` is only ever `admin_fee_pln`; typed `ExtractionError` codes; first named invariant test `test_invariant_rent_is_not_a_deal` (RM-84)
- GDPR: nightly retention sweep (sessions, login tokens, listing snapshots, audit events; proposed periods via `RETENTION_*`), account erasure with an `erasure_log` of hashes (new table, migration `0003`; **operator action:** `make migrate`), re-erasure after a restore, data-subject export, runbook `docs/RUNBOOK-GDPR.md` (RM-30)
- The whole app runs in Docker: `deploy/Dockerfile` (non-root, uv lockfile build), `deploy/compose.yml` (postgres, one-shot bootstrap, api, worker), idempotent `scripts/bootstrap.py` (migrations, Procrastinate schema once, seed), `make up|down|logs|smoke`; **removed** `deploy/compose.dev.yml` (use `deploy/compose.yml`); `make procrastinate-schema` is now `make bootstrap` (RM-69)
- CI: `migrations` job enabled and required on `staging` (squawk + pytest-alembic); migrations now run with `lock_timeout` 5 s and `statement_timeout` 5 min; `.env.example` rewritten with where-to-get comments and new names `RELEASE`, `POSTGRES_IMAGE`, `POSTGRES_PORT`, `ADMIN_EMAIL`, `STRIPE_PRICE_ID_PRO`, `OPENROUTER_CALL_ESTIMATE_USD`, `IMAGE_HOST_ALLOWLIST` (RM-68)
- Vision client: OpenRouter client (`OPEN_ROUTER_API_KEY`, 120 s total, 3 attempts, budget-gated, `usage.cost` kept as `Decimal`), box-wide cap of 4 calls in flight (Postgres advisory locks, self-healing), photo pipeline (https host allow-list `IMAGE_HOST_ALLOWLIST`, 10 MB / 40 MP caps, EXIF and GPS stripped, 1,600 px downscale, near-duplicate removal, 25 photo / 2 plan limits); new env names `OPENROUTER_CALL_ESTIMATE_USD`, `IMAGE_HOST_ALLOWLIST`; new dependencies `pillow`, `httpx` in rm-worker (RM-23)
- Otodom fetch client: strict listing-ref parser (SSRF-safe), `curl_cffi` transport with a hard total timeout and size cap, shared 1 req/s slots and a 15-minute circuit breaker in new table `app.host_throttle` (**operator action:** `make migrate`, migration `0002`), 6-hour cross-tenant snapshot reuse, typed errors `LISTING_GONE` / `UPSTREAM_BLOCKED` / `UPSTREAM_SCHEMA_DRIFT`; new dependency `curl-cffi` (RM-22)

### Changed
- Monitoring moves from Sentry to **Better Stack** (ADR 0009): errors still go through the Sentry SDK, so `SENTRY_DSN` now takes the Better Stack Errors DSN; uptime and the backup heartbeat use Better Stack; `SENTRY_CRON_BACKUP_SLUG` and `SENTRY_CRON_CHECKIN_URL` are replaced by `BETTERSTACK_HEARTBEAT_BACKUP_URL`; **operator action:** create the Better Stack application, uptime monitor and heartbeat (B-001) (RM-112)
- CI: semgrep `no-float-money` no longer flags every `float` annotation (timeouts, sample rates); it now catches money-named floats in annotations, parameters, `Mapped[float]` and `float(...)` calls, also covers `apps/`, and its rule tests run in the `security` workflow (RM-55)
- Flat package layout: `packages/rm_core`, `packages/rm_contracts`, `services/rm_api`, `services/rm_worker` (folder = module, no `src/`, ADR 0008); no import or API change; run `uv sync --all-packages --group dev` again (RM-61, RM-63)
- Engines are written from scratch; the POC is reference only (ADR 0001) (RM-2)
