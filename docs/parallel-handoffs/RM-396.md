## What was built

`rm_core/location_indicators.py`, pure and deterministic (`Decimal`, ROUND_HALF_EVEN, no float, no money):
`resolve_measured` (direct vs labelled `proxy`; the measured unit is always named), `intensity` (numerator /
denominator * per, only for the same measured unit; zero denominator and mismatch are typed states),
`trend` (consecutive-year steps + first-to-last span via `compare_years`, boundary breaks withheld, suppressed
below `min_trend_steps`), `compare_to_parent` (reads the published parent, never averages children),
`compare_to_peers` (siblings under one parent, competition rank, midrank percentile, peer median, cohort id and
coverage; suppressed below `min_peers`), `rank_indicator` (gate via `evaluate_gate`; suppressed or undecided
policy exposes no ranking, only coverage and reasons), and `snapshot_from_release` (reads the CURRENT release only,
`NoReleaseError` otherwise; result carries a SHA-256 digest that is identical on every recomputation).
Publication itself is the existing fail-closed `PgLocationRepo.publish`; tests prove an incomplete run, an
undecided policy and a failed refresh leave the prior release and its snapshot unchanged.
Thresholds (`IndicatorThresholds`) are required inputs with no defaults; tests use TEST-ONLY values. `BDL_BINDINGS`
stays `{}` (asserted). No composite index, no multiplier, no property-grade substitution.
