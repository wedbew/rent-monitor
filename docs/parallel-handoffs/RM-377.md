## Deviations from the startup guide (reasons)

- Startup suggested `packages/rm_core/repositories/market.py` and a `repositories/` export. That directory would
  hold one file (`rules/repo-layout.md`), and `rm_core` does not declare `rm-contracts` as a dependency (it would
  need a manifest and lock change, a reserved file). The Protocol lives with the contracts; the Postgres
  repository should be `packages/rm_core/market_corpus.py` (flat, like `comparables.py`) once the migration owner
  adds the dependency or moves the Protocol.
- Startup model sketch used `int` area and per-offer `ImportCheckpoint` with `seen_offer_ids`. Replaced by
  `Decimal` area (matches `RentComparableRow`), the spec's run/checkpoint split, and no in-memory id sets
  (dedup is the store's unique key, retry-safe across processes).
- `tests/integration/test_otodom_corpus.py` (real Postgres) is NOT written: no tables exist. The unit contract
  tests are written so the Postgres slice adds a second fixture parameter and reruns them.
