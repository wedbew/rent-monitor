## What was built

`BdlClient` (injectable `httpx.AsyncClient`, per-request timeout 20 s capped by the caller's `Deadline`, one retry on
transport error / 502-504, response size cap, HTTP 429 raises `BdlQuotaExhausted(retry_after_s)` and is not retried),
`QuotaGate` protocol with a process-local `SlidingWindowQuota` (windows are caller-supplied, none baked in),
`BdlCursor` (plain value: variable, level, years, page; the caller persists and resumes), `BdlObservationValidator` +
`BdlMetricBinding` (rejects unknown variable ids, wrong units, unselected metrics, foreign years/territories, unpublished
levels and conflicting duplicates; gaps become `missing` / `suppressed` / `invalid_attribute` observations or raise
`GapError` in strict mode; per-row SHA-256 `source_digest`; values `Decimal`, never float).
Fixtures are hand-built; variable `TESTV1` and `test_*` keys are test-only. No metric is selected or activated.
