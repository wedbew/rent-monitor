## What was built

Migration 0016 (expand-only, new tables): `location_reference` + `location_territory` (versioned, immutable, composite
parent FK, unique TERYT per level), `location_observation` (insert-once, immutable, typed gaps, no price columns),
`location_ingest_run` (deterministic run id, page cursor, lease), `location_publication` (immutable) +
`location_publication_pointer` (atomic pointer), `location_quota_stamp`.
`PgLocationRepo`: reference round trip, page cursor and the page's observations committed in one transaction under a lease,
replay of a saved page is a no-op, skipping is refused, source revisions are counted as conflicts (first fact stays),
`publish` fails closed (complete run + decided policy + passed gate, else nothing changes).
`PgQuotaGate`: one request budget shared by all workers (advisory lock, database clock). `ingest_variable` + task
`ingest_bdl_variable` (batch queue): resumes at the cursor, fills typed `missing` rows at completion, marks bad data `failed`
(terminal) and outages `incomplete` (resumable, Procrastinate retries `BdlUnavailable`). `BDL_BINDINGS` is empty: no metric is
selected or activated, so the task refuses every variable before any request. Tests use `TESTV1` / `test_population` only.
