## What this slice is

An importer that drives `CorpusRepository` through an injectable search source: full bootstrap per location with disjoint created-date partitions when a result is deeper than the 50-page cap (bisection down to one hour; a window that still overflows makes the run `incomplete`, never published), nightly new-offer windows with frozen hour-aligned bounds starting `covered_until - 60 min`, catch-up of missed days as chained runs of at most 7 days (mode `recovery`), per-location Postgres advisory lock (overlap-safe), restart as a new attempt on the same window (`-aN` run id), strict page validation (malformed means `incomplete`), valid empty search means published. Insert-once; nothing is refreshed; no listing page is visited. Two Procrastinate tasks: `sync_corpus_location` (queue `batch`) and a periodic `dispatch_corpus_nightly` (queue `ops`, `0 1 * * *` UTC) that does nothing while no catalogue version 1 exists. The client refuses any created-date filter until `OtodomClient.filters_verified` is set (L-050); production builds leave it `False`, so nothing can reach Otodom with this slice alone.
