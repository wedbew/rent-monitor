# V2 review before V3

13 October 2026 · Reviewed source, desktop render and local live home.

## Keep

- Persistent navigation with separate Pulpit, Moje analizy and Rynek URLs.
- Architectural identity, precise edges and strong typographic hierarchy.
- A single URL task with visible credit cost and confirmation before starting.
- Separate analysis objects; warnings travel with the apartment.
- Polish-aware collection search, recovery states, native dialogs and reduced-motion rules.
- Offer-price/transaction-price distinction and administrative-fee semantics.

Confirmed in the live V2 browser: an empty listing URL produces the field error; a valid Otodom-shaped URL opens credit confirmation. These actions do not transmit the link. The source shows a complete 12-item fixture cohort and a separate report route.

## Improve

- V2 only supplies a dark palette. A light default needs a complete token system, with dark retained as a deliberate option.
- Its large photographic hero and uppercase headline dominate a working page. V3 uses a quieter architectural task panel and sentence-case hierarchy.
- Mostly black/gray surfaces have little local identity beyond the image. V3 draws on Polish modernist residential architecture, forest tones, drafting marks and precise local wording.
- The report is explicitly a navigation scaffold. V3 turns it into a navigable information prototype with a next action and four understandable sections.
- V2 has no login design. V3 adds a coherent split-screen entry with mobile reflow and visible recovery paths.

These are design judgments, not measured usability findings. V2's written QA record describes broader prior checks; this review does not claim to have repeated all of them. No production readiness or financial accuracy is established by fixture-only UI verification.
